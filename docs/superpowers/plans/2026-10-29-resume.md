# yuanguo Resume Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在上线的网站新增有清晰职业定位、可打印的公开求职简历。
**Architecture:** 新增 Markdown 简历和 EJS 布局；独立 CSS 管理页面与打印样式，原站主题保持共享。
**Tech Stack:** Hexo、EJS、CSS、原生 JavaScript、Node test。
**Spec:** `docs/superpowers/specs/2026-10-29-resume-design.md`

## Global Constraints
- 姓名全部使用 yuanguo，原文件与隐私字段不进入仓库。
- 早期详情据 2021 年 11 月简历，追加用户确认的 2021—2023 洲斯软件经理、2023—至今南京沃旭 UWB / 无线 / EPD 系统开发经历。
- 不虚构求职经历、数据、学历或技术熟练度；保持原资料中“熟悉”和“了解”的区别。

## Review Focus
- 公开内容和资料时点与历史来源一致。
- 导航加入口后小屏不溢出，简历页锚点存在。
- 无 JavaScript 时正文完整、普通链接可用。
- 深色主题下打印仍为黑白可读。
- 求职页元数据不误用小说封面。
