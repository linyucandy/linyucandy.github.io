# yuanguo 作家主页与作品阅读站

用户已确认作者为 yuanguo，林屿为《糖是凉的》主人公，并于 2026-10-29 同意作家主页与作品阅读站方向。

## 目标与内容
- 首页介绍 yuanguo，推荐《糖是凉的》，引导了解作品与开始试读。
- 作品书架、独立作品介绍、创作手记、关于作者与试读页面形成完整导航。
- 作者介绍仅使用已确认事实，不把小说人物经历当作作者履历，不编造联系方式、奖项、发行状态。
- 取本地终校阅读稿前两章作为试读，展示全书目录，其余章节无虚假阅读链接。
- 手记是本次整理的作品导读，明确标注，避免冒充作者原始自述。

## 设计与交互
现代文学杂志风格，米白底、深灰字、橘糖色与橄榄绿。封面使用可维护的原创 SVG 图形，围绕糖纸与树的意象。布局适配窄屏，正文宽度与行距利于阅读；支持持久化深浅主题、阅读字号调整、上下章导航。无 JavaScript 时内容与链接仍可用。

## 方案与约束
沿用 Hexo + GitHub Pages（用户已选），Markdown 管理内容，独立 EJS 主题管理视觉。静态手写站维护目录和文章成本较高；迁移新框架会浪费已有环境。无需账户、数据库或评论系统。发布目标为现有 GitHub Pages，不注册 Sites 托管。

## 验证与交付
构建真实 HTML 后检查作者署名、试读来源、内部链接与资源，预览桌面与窄屏，验证主题及字号。准备 GitHub Actions 自动部署流程和维护说明。保留已有本地改动，在独立功能分支实施；公开部署仅在连接能力支持时执行并据实报告。
